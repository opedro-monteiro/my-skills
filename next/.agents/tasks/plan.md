# Implementation Plan

## Design decisions

- **Skill name and location:** use `nextjs-app-router-patterns` at `next/nextjs-app-router-patterns/SKILL.md`. The lowercase-hyphen name satisfies the create-skill naming rules and distinguishes this guidance from generic React or TypeScript advice.
- **Progressive disclosure:** keep the routing description, decision rules, workflow, validation, and pitfalls in `SKILL.md`; move detailed examples into three topic-focused files under `references/`. This follows the create-skill guide and the existing `react/react-patterns` convention while keeping the main skill concise and under 500 lines.
- **Scope boundary:** cover Next.js App Router architecture only. Explicitly exclude Pages Router migrations, generic React component design without Next.js concerns, and TypeScript-only guidance so the description routes accurately and does not overlap the existing React/TypeScript material.
- **Repository constraints:** modify only `next/`; treat `.agents/skills/create-skill/` as read-only. The repository has no dependency manifest, build/test scripts, `eng/skill-validator`, `CODEOWNERS`, or existing `eval.yaml` convention, so use deterministic local structural/link validation plus manual semantic review and record the guide’s unavailable repository-level checks truthfully rather than inventing infrastructure or editing outside scope.

## Required frontmatter

```yaml
---
name: nextjs-app-router-patterns
description: Applies Next.js App Router architecture patterns for Server and Client Component boundaries, "use client", project folders, route groups, loading.tsx, error.tsx, and empty states. USE FOR: creating, refactoring, organizing, or reviewing Next.js App Router pages, layouts, components, and route trees. DO NOT USE FOR: Pages Router migrations, generic React component design without Next.js routing or rendering concerns, or TypeScript-only guidance.
---
```

The description leads with an action verb, names concrete artifacts and user intents, stays below 1,024 characters, contains no XML-like tags, and partitions the Skill from nearby React and TypeScript guidance by the actual Next.js App Router concern.
